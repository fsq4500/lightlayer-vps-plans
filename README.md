公开测评记录里，圣何塞优化线路到国内三网的延迟大多落在 130–190ms 区间。电信 128–177ms、移动 126–181ms，两端都算稳；联通延迟明显高一截，晚高峰还有抖动。测评给出的回程路径是电信走 CN2、移动走 CMIN2、联通走 9929+4837。

这条对联通宽带用户几乎是决定性的。同一台机器，电信用户体验和联通用户体验是两回事，测评作者本人的结论也是“电信和移动延迟较低，联通可能抖动”。

顺带说一个判断基准：美西到国内的物理延迟下限就在 130–180ms，这是跨太平洋海底光缆在加州登陆决定的，美东则普遍 200ms 以上。看到任何商家宣传“50ms 回国”，可以直接划走。
